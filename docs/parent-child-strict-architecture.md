# 隐藏项目关联（最终口径）

## 核心规则

- 只有内置账号 `admin` 可以建立、结束项目关联。
- 其他 `role=admin` 账号不能管理关联。
- 关联关系仅内置 admin 可见。
- 子项目页面、导出、搜索、附件和日志都不显示父项目。
- 项目成员权限严格按当前项目判断，父子关系不授予任何账目访问权。

## 动态应收

项目自身存储基础应收和合同调整；关联子项目应收不复制进父项目流水。

```text
父项目总应收
= 父项目基础应收
+ 所有生效直接关联子项目的当前基础应收
```

子项目合同金额变化后，父项目总应收实时变化；父项目历史流水不修改。

## 三种建立方式

1. 新建子项目时直接选择父项目——仅内置 admin 可选。
2. 已有子项目新建父项目——内置 admin 在关联页选择已有项目后新建。
3. 已有父项目和子项目——内置 admin 在关联页建立隐藏关联。

三种方式最终都生成同一种 `project_links` 记录。

## 子项目隔离

- 子项目的 `parent_project_id` 为 NULL。
- 关联只保存在 `project_links`。
- 子项目只知道自己的业主、合同、流水、资金池和利润。
- 不生成“来自 A”的收入，也不生成“外部委托方”等虚假名称。

## 关联生命周期

```text
生效中 → 已结束
```

结束后，父项目总应收实时扣除该子项目当前应收；子项目继续独立运行。

## 删除保护

- 有生效关联子项目时，父项目不能删除。
- 存在生效父关联时，子项目不能删除。
- 必须先由内置 admin 结束关联。

## 数据迁移

迁移 `0006`：

- 新建 `project_links`；
- 将旧 `projects.parent_project_id` 关系迁入；
- 清空子项目的 `parent_project_id`，防止继续泄露父项目；
- 不改动历史流水、成员关系和项目合同金额。
