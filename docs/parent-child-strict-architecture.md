# 主合同项目与分包项目（严格隔离）

## 基本原则

- 父子关系只表示合同来源，不授予任何账务访问权限。
- 每个项目都是独立利润中心，收入、支出、资金池、利润和分红分别核算。
- 父项目只看自己直接签订的分包合同金额和付款，不查看分包项目内部流水。
- 分包项目只看自己与主项目有关的合同、应收和收款，不查看主项目外部合同与利润。
- 管理员可以查看全部项目；普通用户必须显式加入目标项目。

## 权限矩阵

| 用户身份 | 主项目 A | 分包项目 B | 分包项目 C |
|---|---:|---:|---:|
| 管理员 | 可看 | 可看 | 可看 |
| A 成员 | 可看 | 不可看 | 不可看 |
| B 成员 | 不可看 | 可看 | 不可看 |
| A+B 成员 | 可看 | 可看 | 不可看 |

搜索、导出、财务待办、附件下载和审批入口使用同一隔离规则。

## 合同金额

分包项目的 `expected_income_cents` 是当前有效分包合同金额。

主项目不复制一笔固定分包支出，而是实时计算：

```text
当前分包合同合计 = 所有直接分包项目的当前合同金额之和
```

分包合同金额修改后，主项目当前承诺立即变化；已实际支付流水不回写、不篡改。

## 内部结算流程

```text
主项目发起分包付款
→ 主项目生成待打款支出
→ 财务打款
→ 分包项目生成待确认收入
→ 分包项目确认收款
→ 内部结算闭环
```

内部结算记录两侧流水：

- 主项目侧：分包成本支出
- 分包项目侧：分包收入

两侧不自动向对方暴露完整账本。

## 动态指标

```text
主项目当前分包承诺 = Σ 直接分包项目当前合同金额
主项目已付分包款 = 已打款内部结算合计
主项目待付分包款 = 当前合同 - 已付款 - 待打款
主项目多付金额 = max(已付款 - 当前合同, 0)
```

分包项目：

```text
当前分包合同 = 本项目合同金额
已收款 = 已确认收到的内部结算
待确认收款 = 主项目已付款但尚未确认的内部结算
未收款 = max(当前合同 - 已收款, 0)
```

## 分红

- 主项目和分包项目分别配置分红对象。
- 父子项目不自动汇总利润，也不自动把子项目利润回流给父项目。
- `can_dividend=False` 只关闭当前项目的独立分红入口。

## 数据迁移

迁移 `0005` 只新增 `project_subcontract_settlements` 表，不修改历史流水、合同金额或成员关系。
