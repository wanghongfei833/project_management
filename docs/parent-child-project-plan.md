# 父子项目功能 — 技术方案

## 一、概述

支持项目以树形结构组织：父项目可查看所有子项目数据，子项目拥有独立的成员、流水和分红控制。

### 核心能力
- 多级嵌套（2 级 / 3 级 / N 级）
- 子项目对外部人员隐藏父子关系，看起来是完全独立的项目
- 子项目可设置是否允许分红
- 不可分红的子项目，利润自动回流到父项目
- 父项目成员可穿透查看子项目（但操作权取决于是否加入子项目成员列表）

## 二、数据模型

### Project 表新增字段

```python
class Project(db.Model):
    ...
    parent_project_id = db.Column(
        db.Integer, db.ForeignKey("projects.id"), nullable=True, index=True
    )
    can_dividend = db.Column(db.Boolean, nullable=False, default=True)

    # ORM 关系
    parent_project = db.relationship("Project", remote_side=[id], back_populates="sub_projects")
    sub_projects = db.relationship("Project", back_populates="parent_project")
```

### 约束
- `parent_project_id IS NULL` = 独立项目 或 已经是父项目
- `parent_project_id IS NOT NULL` = 子项目
- 禁止循环引用（A→B→A）
- 禁止多层嵌套深度限制（一条外键天然支持 N 级）

## 四、权限模型

### 可见性（读权限）— 递归向上穿透

```python
def _can_view_project(user_id, project_id) -> bool:
    """用户是否能查看某个项目。
    规则：用户自己是该项目的成员，或用户是其任意父级项目的成员。"""
    visited = set()
    p = db.session.get(Project, project_id)
    while p:
        if p.id in visited:
            break
        visited.add(p.id)
        if _is_project_member(p.id, user_id):
            return True
        p = p.parent_project
    return False
```

### 可见性矩阵

| 用户所在项目 | 能看到 A | 能看到 A1 | 能看到 A1a |
|---|---|---|---|
| A 成员 | ✅ | ✅ | ✅ |
| A1 成员 | ❌ | ✅ | ✅ |
| A1a 成员 | ❌ | ❌ | ✅ |

### 操作权（写权限）
不变——谁在 `ProjectMember` 里谁操作。父项目成员不自动获得子项目的操作权。

### 审批
谁在 A1 成员列表里谁审批，不穿透。

## 五、`can_dividend` 的控制逻辑

| 功能 | `can_dividend=True` | `can_dividend=False` |
|---|---|---|
| 项目详情页分红区域 | ✅ 显示 | ❌ 隐藏 |
| 仪表盘分红按钮 | ✅ 显示 | ❌ 隐藏 |
| 利润归属 | 项目自己留着分红 | 终止时利润回流到父项目 |
| 分红入口 | 正常 | 全部隐藏 |

## 六、利润回流机制

### 公式

```
父项目可分红基数 = max(父自己利润 + Σ(不可分红子孙项目利润), 0)
```

其中每个项目的利润 = **已结算收入 - 已结算支出（不含分红）**，与实际到账流水挂钩，与合同预期金额无关。

### 示例

```
A（父，可分红 ✅）
├── A 自己：收入 0，支出 0，利润 0
│
├── A1（不可分红 ❌）
│     ├── 收入 8W，支出 5W，利润 3W → 回流 A
│     └── A1a（不可分红 ❌）
│           ├── 收入 2W，支出 1W，利润 1W → 回流 A1 → 最终回流 A
│
└── A2（可分红 ✅）
      ├── 收入 6W，支出 2W，利润 4W → A2 自己留着分红
      └── 不影响 A 的可分红基数

A 的可分红基数 = 0（自己）+ 3W（A1）+ 1W（A1a）= 4W
A2 的可分红基数 = 4W（独立）
```


## 九、仪表盘

| 项目类型 | 显示 |
|---|---|
| **独立项目** | 正常 |
| **父项目** | 财务=汇总（含回流），进度条改显示「含 N 个子项目」 |
| **子项目（不可分红）** | 正常显示，但无分红按钮 |
| **子项目（可分红）** | 和普通项目完全一样 |
