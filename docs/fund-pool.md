# 项目资金池

## 账户口径

每个项目有两个虚拟资金账户：

- `public`：对公账户
- `pool`：项目资金池

资金池是项目可用资金，不等于额外收入，也不等于个人收入。每个项目资金池可设置一名保管人。

## 三类业务

1. **外部收入**
   - 收入登记时选择“到账账户”。
   - 可到账到对公账户或项目资金池。
   - 计入项目收入，影响项目利润和应收款。

2. **真实支出**
   - 支出登记时选择“付款账户”。
   - 可从对公账户或项目资金池支付。
   - 计入项目支出并影响项目利润，同时减少对应账户余额。

3. **内部资金划转**
   - 对公账户 → 项目资金池
   - 项目资金池 → 对公账户
   - 不计收入、不计支出、不影响项目利润；只改变资金所在账户。
   - 划转可上传银行流水、工资单、转账截图等凭证。

## 工资形式资金

如果一笔工资转账中同时包含真实工资成本和代管项目资金，应拆分登记：

- 真实工资部分：登记为支出，付款账户选择公户或资金池。
- 代管项目资金部分：登记为资金划转。

例如工资名义转出 50,000 元：

```text
真实工资成本 5,000 元：登记支出（公户付款）
代管项目资金 45,000 元：公户 → 资金池划转
```

不能把全部 50,000 元都登记成资金划转，也不能把项目代管资金登记成工资成本。

## 余额计算

```text
对公余额 =
公户到账收入
- 公户付款支出
- 公户划入资金池
+ 资金池划回公户

资金池余额 =
资金池到账收入
- 资金池付款支出
+ 公户划入资金池
- 资金池划回公户

项目可用资金 = 对公余额 + 资金池余额
```

资金划转不影响项目利润。项目利润只由到账收入和真实支出决定。

## 历史数据

迁移 `0003` 会把上线前的全部历史收入、支出默认归入“对公账户”。因此历史项目余额不变，资金池初始余额为 0。
