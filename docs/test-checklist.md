- [ ] 编辑项目时可以修改「允许分红」开关

### 2.6 子项目分红数值校验

以下用同一个例子验证数值正确：

**父项目 A**（合同 10W）：
- A1（子项目，不可分红，合同 5W）
  - 收入：已到账 3W
  - 支出（非分红）：1W
  - 利润：3W - 1W = **2W** → 回流父项目
- A2（子项目，可分红，合同 5W）
  - 收入：已到账 4W
  - 支出（非分红）：1.5W
  - 利润：4W - 1.5W = **2.5W** → A2 自己留着分红

**父项目 A 的汇总**：
- A 自己利润：0
- + A1 回流：2W
- = A 可分红基数：**2W**
- A2 独立分红：2.5W（不影响 A）

- [ ] 父项目 A 的可分红基数 = **2W**
- [ ] A1 页面无分红入口
- [ ] A2 页面可分红基数 = **2.5W**
- [ ] A2 可以正常划出分红

## 八、财务数值正确性（核心校验）

以下用实际数据验证每个场景的金钱流转是否正确。

### 8.1 子项目不可分红 + 收入>支出

```
A1（不可分红）
  收入：5W
  支出：2W
  利润：5W-2W = 3W → 回流到父项目 A
父项目 A 的可分红基数应包含这 3W
```

- [ ] A1 页面**无**分红入口
- [ ] 父项目 A 的汇总利润包含 A1 的 3W

### 8.2 子项目可分红 + 收入>支出

```
A2（可分红）
  收入：8W
  支出：3W
  利润：8W-3W = 5W → A2 自己保留
```

- [ ] A2 分红页面显示可分红 **5W**
- [ ] A2 可以划出分红
- [ ] 父项目 A 的汇总**不包含** A2 的 5W（因为 A2 可分红）

### 8.3 收支平衡（收入==支出）

```
收入：3W
支出：3W
利润：0
可分红：0
```

- [ ] 分红页面显示「无可分红金额」

### 8.4 部分分红已完成

```
总利润：5W
已分红：2W
剩余可分红：3W
```

- [ ] 分红页面：已登记=2W，剩余=3W
- [ ] 再次分红划出 3W 后剩余=0

### 8.5 父项目汇总多个子项目（混合）

```
父项目 A
  ├── A1（不可分红）：利润 3W → 回流
  ├── A2（可分红）：利润 5W → 独立
  └── A 自身：利润 0
      父项目可分红基数 = 0 + 3W = 3W
      A2 可分红基数 = 5W（不受影响）
```

- [ ] 父项目 A 的可分红基数 = **3W**
- [ ] A2 的可分红基数 = **5W**
